# Débuter en Java

L'objectif de ce document est de lister une série de ressources 
pour débuter en Java tout en pratiquant.

Pour maîtriser les notions de base en Java, l'étudiant devra : 
- **Lire tous les chapitres**
- **Réaliser tous les exercices** dans le cadre de ces tutoriels
